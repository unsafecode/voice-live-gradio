# Plan tiers and SLAs

## Free

- 1 vCPU, 5 GB object storage, 100,000 API requests per month
- Community support via the forum, no SLA
- One region

## Pro — $49 per user, per month

- 8 vCPU, 100 GB object storage, 5 million API requests per month
- Email support, 24-hour first-response SLA on weekdays
- Logs retained 30 days
- Up to three regions

## Enterprise — custom pricing

- Unmetered compute and storage (fair-use), unlimited API requests
- **24/7 priority support with a 4-hour first-response SLA on
  Severity-1 incidents**
- **A dedicated Technical Account Manager (TAM) is assigned within
  30 minutes of any Severity-1 escalation**
- Logs retained 365 days
- All regions, including private regional deployments on request
- Custom contractual terms, audit reports (SOC 2 Type II, ISO 27001)

## Plan changes

Upgrading from Free to Pro or Pro to Enterprise is instant. Downgrades
take effect at the end of the current billing period to avoid
prorating headaches.
